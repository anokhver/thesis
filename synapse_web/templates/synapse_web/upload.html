Pick a folder that contains your Olympus cellSens acquisitions. Each acquisition is a triplet: the .vsi scene file, its .oex acquisition plan, and the _<name>_/ companion folder that holds the .ets tile cache. All three must sit next to each other because the loader reads the tile cache through the .vsi. 

my_session/
├── 2_3_PSYHARMIN_7_Multichannel Z-Stack_20251030_72.vsi
├── 2_3_PSYHARMIN_7_Multichannel Z-Stack_20251030_72.oex
├── _2_3_PSYHARMIN_7_Multichannel Z-Stack_20251030_72_/
│   └── ...ets tile data...
├── 2_5_BAEO_3_Multichannel Z-Stack_20251030_73.vsi
├── 2_5_BAEO_3_Multichannel Z-Stack_20251030_73.oex
└── _2_5_BAEO_3_Multichannel Z-Stack_20251030_73_/
    └── ...

All .vsi files found anywhere inside the chosen folder are registered as separate acquisitions. We assume one .vsi = one Z-stack (single time frame, multiple channels and Z-slices is fine).
