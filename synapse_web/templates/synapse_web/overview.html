Overview

{% card title="Pipeline" %}

The SynAPSeg thesis pipeline ingests 3D confocal fluorescence Z-stacks, projects them to 2D via Maximum Intensity Projection, normalises per channel, and tiles the result into 128 × 128 patches. A self-supervised Swin-based autoencoder is pretrained on those patches. This web front-end then runs the clustering analysis on top of the trained encoder: it extracts patch embeddings and groups them with Leiden, producing per-image cluster summaries and statistical comparisons across treatment groups.
